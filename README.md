# developer-excuses

One funny single-line excuse a developer gives when code breaks in production.

## Entry

> I fixed the bug by deleting the only line that worked — turns out it was load-bearing.

## Run

```sh
node main.ts
```

This writes the excuse to `/output/entry.txt` (86 characters, UTF-8, deterministic — byte-identical on every run).
